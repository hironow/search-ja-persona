# ゴールデンセット強化と判別力診断 (2026-08-27)

**Snapshot date:** 2026-08-27
**Index:** full corpus 1,000,000 personas / ruri-v3-310m (768 dims)
**Harness:** `just eval`（レポート schema v2）+ `just diagnose`
（`scripts/diagnose_golden.py`、新設）
**動機:** requester 指摘「明らかな正解はちょっと eval としては親切すぎる」。

## 原因分析の訂正

初期仮説「ES レグがクエリ語のキーワード一致を top-5 に混入させるから
述語が自動的に満たされる」は**実装と不一致**だった。`search.py` の融合は
vector ヒットを先に詰め、ES 固有ヒットは末尾追記後に `[:limit]` で
切られる。全量インデックスでは Qdrant が常に limit 件返すため
**top-5 は純ベクトル順**（診断でも fused×keyword の uuid 重複は
ほぼ 0.00）。真因は 2 つ:

1. **述語とクエリの語彙的非独立性** — text_any にクエリ語自身が並ぶ。
2. **退化した述語** — ランダムなペルソナでも高率で合格する述語。
   全ペルソナが 6 分野（professional/sports/arts/travel/culinary/
   summary）のテキストを必ず持つコーパス構造上、分野汎用語
   （料理・食材・音楽 等）の text_any は基底一致率が跳ね上がる。

## 測定方法（v2）

- 各エントリに `tier: basic | hard`。**basic = 既存 12 クエリを凍結**
  （intent.md の承認済みバー「golden mean precision@5 ≥ 0.85」が参照
  する量。レポートの `golden_mean_precision` は basic 平均のまま）。
- `text_all`（CNF: 各グループは必須語 or 同義語群）を追加し、hard 12
  クエリを新設 — 複合側面 4 / 地理×テーマ 4 / パラフレーズ系 4。
- `load_golden_queries()` が実行時とテストの双方でスキーマ検証
  （未知キーは黙殺され「全件合格」に化けるため fail fast で拒否）。
- **判別力診断** `just diagnose`: 同一述語を fused（本番融合）/
  keyword（ES BM25 単独）/ random（シャード 0 から seed 20260827 で
  200 件、インデックスと同じ 6 フィールド結合テキスト）の 3 系統で
  採点し、fused top-5 のスニペットと per-hit 判定も保存する。

## 述語キャリブレーション（診断ループ 2 周）

- 初版 hard の「食卓を自分の手で豊かに…」は **random 0.985** で退化
  （culinary_persona 由来）→ パン・菓子作りクエリに交換。
- 「言葉や物語…」は random 0.24 + 文学的人名への誤引きでノイズ →
  ミステリー特化クエリに交換。「手先が器用…」はクエリ字義が熟練職人
  も含み述語意図とズレ → 「趣味で小物や雑貨を手作り…」に固定。
- 汎用語の除去（ウォーキング・工芸 等）で hard の random 平均は
  **0.164 → 0.047**（最大 0.205）。

## 知見

1. **人名汚染（headline）**: ベクトル検索がペルソナ本文冒頭の氏名に
   強く引っ張られる。観測例 — 福岡県クエリに「福岡礼・福岡 太也」
   （福岡姓の非福岡県民）、沖縄クエリに具志堅・与那嶺姓、温泉クエリの
   1 位が「温泉 正次」氏（POS 担当店長）+ 湯本姓 2 名、パン作り
   クエリに「三宅 パン・谷萩 パン・山本 あんこ」氏、文学クエリに
   「川端 書・垰村 詩音」氏。**12 hard クエリ中 6 件で確認**。
   「温泉 正次」氏は本文に名前として「温泉」が出るため述語まで
   欺いた（観測された述語 FP の主例）。
2. **keyword 単独が fused を上回る**（basic 0.983 vs 0.900、hard
   0.583 vs 0.433）。述語が語彙ベースで BM25 に構造的に有利という
   割引は必要だが、地理×テーマ系（温泉 0.40 vs 1.00、福岡 0.60 vs
   1.00 等）の差は実質的で、融合が keyword レグをほぼ捨てている
   （vector が limit を埋め切る）現仕様の改善余地を示す。
3. パラフレーズ系では vector 優位も確認（手作り 0.60 vs 0.20、
   運動習慣 0.40 vs 0.00）— 意味検索が仕事をする局面は確かにある。
4. **basic 側の退化述語**（凍結のため未修正）: 和食料理人
   random **0.980**、茶道書道 0.495、登山 0.380。バーの構成要素の
   ため本 PR では触らず、下記の裁定事項とした。
5. 述語監査: hard の fused top-5 全 60 件を目視レビュー。述語 FP
   1〜2 件（人名由来）、FN 疑い 1〜2 件（運動習慣が 散歩/自転車
   表現で取りこぼし得る）— 誤差 約 3〜7%。述語は下界であり、
   絶対値より経時変化を見る原則は変わらず。

## 改善候補（優先順、いずれも別 work unit）

1. **prefecture の payload フィルタ**（既記録の候補; 再インデックス
   不要）— 地理×テーマ hard 4 クエリと basic 沖縄 0.40 が直接改善。
2. **融合の再設計**（keyword レグの実効化: interleave / RRF 等）—
   knowledge 2 が根拠。検索仕様変更のため要 requester 合意。
3. **人名の埋め込み除外**（インデックス時に氏名を除いて埋め込む）—
   knowledge 1 が根拠。全量再インデックス（~50 分）が必要。
4. **pooled 人手 qrels**（プランレビューで提案された本格 IR 評価）—
   述語下界の限界を外す恒久策。solo 運用ではコスト大、要裁定。
